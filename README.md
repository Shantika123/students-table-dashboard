# Students Table Dashboard

A **frontend web application** built using **React.js** that displays and manages student records in a table.
The application performs **CRUD operations (Create, Read, Update, Delete)** using local state without any backend.

## Features

* Add new student records
* View students in a table format
* Edit existing student details
* Delete student records
* Data managed using **in-memory state / local JSON**
* Simple and responsive user interface

## Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Tailwind CSS



## How to Run the Project

1. Clone the repository

```
git clone https://github.com/your-username/students-table-dashboard.git
```

2. Navigate to the project folder

```
cd students-table-dashboard
```

3. Install dependencies

```
npm install
```

4. Start the application

```
npm start
```

5. Open in browser

```
http://localhost:3000
```

## Learning Outcomes

* React component structure
* Managing application state in React
* Implementing frontend CRUD operations
* Handling user input and table data dynamically
